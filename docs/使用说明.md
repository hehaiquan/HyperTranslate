# HyperTranslate 使用说明

## 启动

本版为当前 Apple Silicon Mac 构建，最低系统版本为 macOS 15。应用位于项目 `dist/HyperTranslate.app`。

1. 将 `HyperTranslate.app` 放到自己打算长期使用的位置，再双击启动。建议放入「应用程序」，避免授权后移动路径。
2. 应用常驻菜单栏，图标是对话气泡，不显示 Dock 图标。
3. 在首次准备页中点击「打开辅助功能设置」，在系统「隐私与安全性 → 辅助功能」中开启 HyperTranslate。如列表中没有应用，可用系统设置的「+」添加实际的 `.app`。
4. 点击「准备语言包」，按系统提示联网下载英文和中文模型。系统可能允许下载在后台继续，此时不代表已经可翻译；稍后点击「检查状态」，确认语言包已安装。取消下载后可重试。
5. 点击「开始使用」。没有辅助功能授权时仍可手动输入或通过菜单翻译剪贴板。

本地版本使用 ad-hoc 签名，不包含 Developer ID 公证。更新后二进制签名可能变化；如果系统要求重新授权，重新添加应用即可。不要关闭系统安全功能。

若系统设置里开关已经开启，但应用仍提示未授权，请先退出应用，把该项关闭再打开，然后重新启动。若仍无效，移除旧项目并用「+」添加当前 `.app` 的实际路径。旧签名的开关状态不能证明当前版本已经获准取词。

## 划词和翻译

- 在网页、可选择文本的 PDF 或编辑器中拖选英文，松开鼠标后约 180 毫秒读取选区。默认使用「手动弹出」：出现「译」小图标，点击后显示结果；图标约 8 秒后自动消失。
- 在「设置 → 选中后如何弹出」中切换为「自动弹出」，即可选中英文后直接打开翻译结果。两种模式均支持鼠标和键盘选区，选项重启后保留。暂停划词时，两种模式都不触发。
- 输入页、设置页或准备页开着也可以划词；系统语言包正在准备时会暂缓划词图标和自动弹窗。每次启动或重新打开应用都会显示页面，缺少划词权限时直接显示授权入口。
- 单词显示中文释义、词性和词库音标。变形词保留自身读音和词义，同时显示原形释义，避免 `saw` 等多义词丢失原本含义。
- 多个词、句子或段落进入英译中模式；空行和段落顺序会保留。每次最多 12,000 个字符，超出时提示缩小选区。
- 点击喇叭朗读英文；再次点击顶部朗读按钮可停止。默认美式英语，可在设置中改为英式英语。
- 点击「复制中文」复制当前释义或译文；原文、释义和译文也支持选择复制。
- 结果可滚动。按 `Esc`、点击外部或切换其他应用可关闭临时结果；系统语言包确认期间会保留宿主窗口。
- 按住顶部应用名称或旁边的空白区域拖动窗口；在浮窗内切换输入、收藏、设置等页面会保留位置。新的划词查询仍跟随选区定位。
- 左侧为独立竖排侧边栏：关闭、手动输入和收藏在上方，设置在底部；当前页面入口会高亮。默认窗口宽 560，输入页高 640，其他页面高 720（macOS 逻辑点）；屏幕空间不足时自动收缩到可见区域。
- 松开后可以移走鼠标；取词会保留松开时的位置。键盘选择英文时也尝试取词，优先按实际选区定位，不要求鼠标停在选区附近。

某些应用不暴露选区，图片和扫描 PDF 也没有可读取的文本。此时请自行复制英文，再点击菜单栏的「翻译剪贴板」，或打开「手动翻译」。应用不会自动模拟复制，也不会后台轮询剪贴板。

如果没有出现图标，可以从菜单打开「权限与语言包」查看最近的「取词状态」。它只显示读取阶段和来源应用名称，不保存选中文字。若一直停在「正在监听划词」，说明尚未收到有效选择事件；若显示某应用未提供选区，可通过剪贴板入口继续使用。

## 例句与联网

释义及音标来自内置 ECDICT；发音和句子翻译使用系统框架。联网只用于补充英文例句，免费接口只接收查询单词，不接收整个选中段落。

每个单词最多显示两条例句，英文出现后再补充系统中文翻译。词形查询时，例句可能按原形查找。例句不按所在文章上下文消歧，可能对应其他词义。

例句缓存位于用户缓存目录 `~/Library/Caches/com.hypertranslate.mac/Examples/`，保存英文、中文、来源、许可和缓存时间。缓存有效期为 30 天，联网失败时可使用已有缓存。不保存句子翻译历史。

在设置中关闭「联网补充英文例句」后，不发起例句请求，也不读取已有例句缓存。词库、例句缺少某项数据时会明确提示，不推测音标或编造例句。

## 菜单栏入口

「手动翻译」支持粘贴英文，点击翻译或按 `⌘ Return` 查询。输入框下方的「清除内容」可一键清空输入，并将光标放回输入框；输入为空时按钮禁用。「翻译剪贴板」仅在点击时读取一次文本。「暂停划词」只关闭自动取词，手动翻译仍可使用。「权限与语言包」可重新检查系统准备情况。「设置」可调整选中后的弹出方式、朗读口音和联网例句。

## 收藏单词

单词结果有中文释义后，点击「收藏」加入单词本；再次点击「已收藏」可取消。句子和段落不提供收藏。收藏保留原选单词、音标、中文释义与收藏时间，变形词不会自动合并到原形；同一单词不区分大小写，不会重复保存。

点击左侧栏星标，或菜单栏「收藏单词…」打开列表。列表按收藏时间倒序排列，可搜索英文单词或中文释义；点击词条重新查询并朗读，点击词条右侧星标取消收藏。已保存的释义在无网络时也能查看，重新查词沿用现有例句与系统翻译设置。

收藏自动保存到 `~/Library/Application Support/com.hypertranslate.mac/Favorites.json`，退出、重启或更新应用后保留。文件写入失败时显示错误，列表不假报成功；文件读取失败时保留原文件，修复后需重启应用。收藏只在本机保存。

当前没有开机自动启动、翻译历史记录、OCR、云同步或账号功能。退出请使用菜单栏的「退出 HyperTranslate」。

## 玻璃外观

浮窗、取词图标和内容卡片使用统一圆角与半透明样式，随系统切换深浅色。macOS 26 及以上使用系统 Liquid Glass；macOS 15–25 使用原生毛玻璃。开启系统「辅助功能 → 显示 → 降低透明度」后，改用实色背景以保持文字清晰。
