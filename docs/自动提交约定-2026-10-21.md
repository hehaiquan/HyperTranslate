# 自动提交约定

日期：2026-10-21

## 原因与范围

根据用户要求，将每次修改完成后自动提交 Git 的约定写入项目根目录 `AGENTS.md`，供后续项目任务执行。

## 执行规则

- 完成修改、记录文档并通过必要检查后，自动创建本地 Git 提交，无需再次确认。
- 只提交当前任务的修改，保留原有未提交内容。
- 提交完成后报告提交哈希和验证结果；失败时说明原因。
- 推送远程仓库仍需用户明确授权。

## 验证

本次仅新增项目协作规则和说明文档，检查新增文件的差异与空白错误，不运行应用构建或功能测试。

工作区原有语音服务、界面、版本配置、测试和文档改动不纳入本次提交。
